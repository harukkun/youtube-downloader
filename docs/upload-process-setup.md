# 업로드 프로세스 — 사용자 설정 TODO

로컬 앱 코드와 테스트는 준비되어 있습니다. 아래 Google Sheets / Apps Script 작업은 사용자가 직접 진행합니다. 유튜브 업로드 연동(v15)은 이 문서 끝의 절을 따릅니다.

## 1. 기존 코드와 시트 백업

1. 현황판 스프레드시트를 엽니다.
2. **파일 → 사본 만들기**로 시트의 백업을 만듭니다.
3. 원래 시트에서 **확장 프로그램 → Apps Script**를 엽니다.
4. 현재 `Code.gs` 전체를 별도 텍스트 파일에 복사해 둡니다.

## 2. 새 Apps Script 코드로 교체

1. 이 프로젝트의 `sheets/Code.gs` 전체를 복사합니다.
2. 원래 시트에 연결된 Apps Script 편집기의 기존 `Code.gs` 내용을 교체합니다. 맨 아래에 중복해서 붙이지 마세요.
3. 저장합니다. 코드의 `UPLOAD_VERSION` 값이 `15`인지 확인합니다.
4. **현황판 Y열(숨김)의 항목 ID가 이미 존재하면 `setupSheets`를 다시 실행할 필요가 없습니다.**
5. Y열/항목 ID가 없는 구버전 시트만 백업을 확인한 다음 `setupSheets`를 실행합니다. ID 중복이 있는 행은 기존 ID를 임의로 복제하지 말고 원본/복제 행을 확인합니다.

## 3. 고급 Google Sheets 서비스 활성화

1. Apps Script 편집기 왼쪽 **서비스 옆 +**를 누릅니다.
2. **Google Sheets API**를 선택합니다.
3. 버전 **v4**, 식별자 **Sheets**로 추가합니다. 이미 있다면 중복 추가하지 않습니다.
4. 별도의 표준 Google Cloud 프로젝트를 연결한 경우, 해당 Cloud 프로젝트의 **API 및 서비스 → 라이브러리 → Google Sheets API → 사용**도 확인합니다. 기본 Apps Script Cloud 프로젝트는 서비스 추가 시 자동 활성화됩니다.

공식 안내: [고급 Google 서비스 활성화](https://developers.google.com/apps-script/guides/services/advanced)

## 4. 권한과 웹 앱 배포

1. **배포 → 배포 관리**를 엽니다.
2. 기존 웹 앱 배포를 선택하고 **수정(연필) → 버전: 새 버전 → 배포**를 누릅니다.
3. 실행 계정은 **나**, 액세스 권한은 기존 앱 연결과 동일한 **모든 사용자**로 유지합니다. 앱은 별도의 업로드 토큰으로 쓰기 요청을 인증합니다.
4. 새 권한 승인이 표시되면 코드와 요청 권한을 확인한 뒤 승인합니다.
5. 기존 배포를 업데이트하면 웹 앱 URL과 저장된 토큰을 계속 사용할 수 있습니다. 별도 새 배포를 만든 경우에만 새 `/exec` URL을 앱에 반영합니다.
6. 웹 앱 `/exec` 주소를 브라우저로 열어 응답의 `version`이 `15`인지 확인합니다.

## 5. 로컬 앱 재시작과 연결 확인

1. 실행 중인 로컬 앱을 종료한 뒤 평소 방법으로 다시 시작합니다.
2. **쇼츠 현황판 → 시트 쓰기 연결**에서 기존 URL·토큰이 유지되는지 확인합니다. 새 배포 URL을 만들었다면 업데이트합니다.
3. 브라우저를 새로고침하고 상단 **업로드 프로세스**를 엽니다.
4. 완료되지 않은 항목을 선택해 기본 정보가 표시되는지 확인합니다.
5. `Google Sheets 서비스` 또는 `버전` 안내가 나오면 2–4단계를 확인합니다. 목록은 보이지만 선택이 실패한다면 시트 읽기 연결뿐 아니라 쓰기 연결·고급 서비스·항목 ID를 확인합니다.

## 6. 테스트 항목으로 전체 흐름 확인

1. 현황판에 작업용 테스트 항목 하나를 준비하고 업로드 완료 이전 상태로 둡니다.
2. **업로드 프로세스**에서 테스트 항목을 선택합니다.
3. 영상 제목·원본 링크·참고 링크를 입력합니다. 설명 입력은 다음 단계에서 합니다.
4. 원본 레시피를 붙여 넣고 SNS 글을 생성합니다. 추가 질문이 나오면 답변합니다.
5. **유튜브** 결과를 수정하고 **유튜브 설명글 확정**을 누릅니다.
6. 썸네일을 만들고 **현재 썸네일 확정**을 누르거나 **기존 썸네일 사용**을 선택합니다.
7. 새로고침하여 초안과 확정한 이미지가 복원되는지 확인합니다. 원본 영상과 미확정 편집 장면은 보관하지 않습니다.
8. 최종 확인에서 먼저 제출 얼럿을 **취소**합니다. 시트가 바뀌지 않아야 합니다.
9. 다시 제출하고 **승인**합니다. 제목·설명·링크·메모·썸네일과 `✅ 업로드 완료` 상태가 반영되는지 확인합니다.
10. 기존 플랫폼 체크·게시 링크·고정 댓글·등록일이 유지되는지 확인합니다.

## 저장·복원 안내

- 초안은 같은 브라우저/사이트 주소에서만 복원됩니다. 다른 PC나 브라우저로 동기화되지 않습니다.
- 썸네일 단계의 **이미지 저장**은 다운로드만 합니다. 시트 반영은 마지막 승인 때 이루어집니다.
- 저장 응답이 끊기면 **저장 결과 확인**을 먼저 누릅니다. 완료 기록이 없을 때만 같은 번호로 재제출합니다.
- 다른 사람이 수정했거나 항목이 삭제되면 초안을 유지하고 제출을 중단합니다. 필요한 내용을 복사한 뒤 **최신 내용으로 다시 시작**을 선택합니다.
- 새 이미지 준비와 시트 저장은 별개입니다. 확실한 실패는 새 파일을 정리하고, 불확실한 결과는 확인 전까지 보관합니다.
- 시트 셀과 제출 기록은 한 번의 Sheets API 요청으로 저장됩니다. Apps Script 잠금은 시트에서 직접 수행하는 동시 편집까지 막지는 않습니다.
- 생성 기능에는 기존 헬퍼에서 사용하던 Codex/Claude 호출 환경이 필요합니다.

## v15: 유튜브 업로드 연동 (YouTube Data API)

최종 확인 단계에서 영상 파일을 고르면 앱이 YouTube Data API 로 **비공개** 업로드하고, 성공하면 현황판 제출 한 번에 상태 변경·▶️ 유튜브 체크·게시 링크를 함께 기록합니다. 아래 순서를 따르세요. 0번은 시간이 걸리므로 가장 먼저 시작합니다.

### 0. 먼저 시작: Google Cloud 프로젝트와 API 감사 신청

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트를 만듭니다(기존 프로젝트도 가능).
2. **API 및 서비스 → 라이브러리 → YouTube Data API v3 → 사용**.
3. **YouTube Data API v3 → 할당량** 페이지의 안내(또는 [API 규정 준수 감사 양식](https://support.google.com/youtube/contact/yt_api_form))으로 **규정 준수 감사(compliance audit)** 를 신청합니다. 용도는 "본인 채널에 쇼츠를 업로드하는 개인 도구"로 설명하고, 요구하면 앱 화면 데모 영상과 개인정보처리방침 URL 을 준비합니다. 승인까지 수 주가 걸릴 수 있습니다.
4. **중요**: 감사를 통과하지 않은 프로젝트로 API 업로드한 영상은 비공개로 잠기고, 이의신청 없이 공개로 바꿀 수 없습니다. 승인 전에는 앱의 **테스트 업로드**만 사용하세요.

### 1. Apps Script v15 배포

1. 위 2절대로 `sheets/Code.gs` 전체를 교체하고 `UPLOAD_VERSION` 이 `15` 인지 확인합니다. `setupSheets` 재실행은 필요하지 않습니다.
2. **배포 → 배포 관리 → 수정 → 새 버전 → 배포**. `/exec` 응답의 `version` 이 `15` 인지 확인합니다.
3. v15 는 `upload_submit` 에 `youtubeUrl` 이 오면 같은 저장 요청에서 ▶️ 유튜브 체크와 링크 열을 씁니다. 14 이하 버전이면 앱이 업로드 전에 막고 안내합니다.

### 2. 로컬 앱 의존성 설치

1. 실행 중인 앱을 종료하고 `run.sh` 를 다시 실행합니다. `requirements.txt` 가 바뀌어 Google 라이브러리를 설치합니다.
2. 설치가 실패하면 앱은 뜨지만 유튜브 기능만 비활성화되며, 설정 패널에 "라이브러리 없음" 이 표시됩니다. 네트워크를 확인한 뒤 `run.sh` 를 다시 실행하세요.

### 3. OAuth 클라이언트 만들기

1. **API 및 서비스 → OAuth 동의 화면**. 채널이 Google Workspace 계정이면 사용자 유형 **내부**, 개인 Gmail 채널이면 **외부**로 만들고 게시 상태를 **프로덕션**으로 전환합니다(테스트 상태면 연결이 7일마다 끊깁니다).
2. 범위에 `.../auth/youtube.upload` 와 `.../auth/youtube.readonly` 를 추가합니다.
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID → 애플리케이션 유형: 웹 애플리케이션**.
4. **승인된 리디렉션 URI** 에 `http://127.0.0.1:8765/api/youtube/oauth/callback` 하나만 추가합니다(포트를 바꿨다면 그 포트). 공개 서버 주소는 공인 IP 라 Google 이 받지 않으며, 연결은 로컬에서만 합니다.
5. JSON 을 다운로드합니다. `{"web":{...}}` 형태여야 합니다.

### 4. 앱에서 연결

1. 로컬(`run.sh`)에서 **업로드 프로세스 → 유튜브 채널 연결** 을 열고 JSON 내용을 붙여 **JSON 저장**.
2. **Google 계정 연결** → 채널 소유 계정으로 로그인(브랜드 계정이면 채널을 고릅니다). 외부·프로덕션 앱은 "Google 에서 확인하지 않은 앱" 화면이 나오면 **고급 → 이동** 으로 진행합니다.
3. 돌아오면 패널에 채널명이 표시됩니다. 갱신 토큰은 `~/.youtube-downloader/youtube_credentials.json`(권한 600)에 저장되며 공개 모드(`run-public.sh`)도 이 파일을 사용합니다.
4. 감사 승인 메일을 받은 뒤 **YouTube API 감사 승인 완료** 토글을 켭니다. 그 전에는 테스트 모드입니다.

### 5. 테스트 업로드로 파이프라인 확인 (감사 승인 전)

1. 테스트 항목을 4단계까지 진행하고 짧은 세로 영상 파일을 선택합니다. 제목은 100자, 설명은 5000바이트(한글 약 1,600자) 이내여야 하며 1·2단계의 카운터로 확인할 수 있습니다.
2. **테스트 업로드 (현황판 제출 없음)** 를 누릅니다. 서버 전송 → 유튜브 업로드 진행률이 표시됩니다. 이 동안 다른 단계로 이동할 수 없고 탭을 닫으면 경고가 뜹니다.
3. 완료되면 링크가 표시됩니다. YouTube Studio 에서 영상이 비공개로 올라갔는지, 새 썸네일을 확정했다면 커스텀 썸네일이 반영됐는지 확인합니다. 쇼츠 커스텀 썸네일은 인증된 채널(파트너 프로그램 우선 적용)에서만 반영되며, 반영되지 않으면 Studio 에서 직접 올립니다.
4. 테스트 영상은 Studio 에서 삭제합니다. 현황판은 바뀌지 않습니다.

### 6. 실제 업로드 (감사 승인 후)

1. 토글을 켠 뒤 항목을 4단계까지 진행하고 파일을 선택합니다. 버튼이 **유튜브에 비공개 업로드 후 현황판에 제출** 로 바뀝니다.
2. 확인 얼럿 승인 → 업로드 완료 → 자동으로 현황판에 제출됩니다. 시트에서 상태 `✅ 업로드 완료`, ▶️ 유튜브 체크, 유튜브 링크 열을 확인합니다.
3. 게시는 YouTube Studio 에서 공개로 바꾸거나 예약합니다. 공개·예약을 앱에서 지정하는 기능은 다음 단계에서 추가합니다.
4. Studio 에서 직접 올린 영상은 **영상 없이 현황판에만 제출** 을 사용합니다.

### 문제 해결

- **유튜브 업로드는 끝났는데 시트 저장이 실패한 경우**: 메시지에 유튜브 링크가 남습니다. 저장 결과 확인 → 재제출을 진행하면 같은 업로드를 다시 쓰며, 영상을 다시 올리지 않습니다. 초안을 "최신 내용으로 다시 시작" 해도 업로드 결과는 서버에 남아 4단계에서 다시 나타납니다.
- **99% 이후 중단**: 재시도 전에 Studio 에 영상이 이미 있는지 확인하세요. 있으면 재시도하지 말고 **유튜브 업로드 기록** 의 링크를 사용하거나 Studio 에서 정리합니다.
- **"Google 연결이 만료되었습니다"**: 동의 화면이 테스트 상태(7일 만료)이거나 권한을 회수한 경우입니다. 프로덕션으로 전환한 뒤 설정에서 다시 연결합니다.
- **"오늘 API 업로드 한도를 넘었습니다"**: 한도는 태평양 자정(한국 오후 5시)에 초기화됩니다. 그 전에는 Studio 에서 직접 올리고 영상 없이 제출하세요.
- **Apps Script 버전 안내**: v15 미만이면 업로드 전에 막힙니다. 1절대로 재배포하세요.
- 로컬 서버(8765)와 공개 서버(8766)를 **동시에** 띄운 채 업로드하지 마세요. 두 서버가 같은 작업 저장소를 쓰며, 늦게 시작한 서버가 진행 중 작업을 "중단됨" 으로 표시합니다.
- 업로드 기록·진행 상태는 `~/.youtube-downloader/hooks/jobs/` 에 편집 헬퍼 작업과 함께 저장되고, 영상 원본은 업로드 성공 시 즉시 삭제됩니다.
