# 현황판 전체 필드 편집 구현 계획 (검토 반영)

## 범위
행 펼침 편집 폼에서 상태·요리 제목·원본 링크/제목/채널·참고 링크/채널·플랫폼 체크/링크·영상 제목·설명·고정 댓글·메모를 편집하고, 3행에 새 촬영 후보를 추가하거나 확인 후 삭제한다. 쓰기는 Flask → Apps Script 웹 앱 경로를 사용한다.
로컬 코드와 자동 테스트까지 구현한다. 실제 시트 확인, Apps Script 적용, setupSheets 실행, 배포, 브라우저 검증은 사용자가 진행한다.

## 식별과 API
- 마지막 숨김 itemId 열에 UUID를 보관한다. 초기 설정으로 기존 실제 행에 부여하고 재실행 시 보존한다. 완전히 빈 예약 행은 제외한다. 후보 추가와 시트 편집에도 부여한다.
- 수정·삭제는 고유 ID로만 식별한다. 없거나 중복되면 row_mismatch(409). row는 위치 정보다. ID 없는 기존 CSV는 읽기 전용으로 유지한다.
- POST /api/shorts/items {fields?}, PUT /api/shorts/items/<row> {item_id, fields}, DELETE /api/shorts/items/<row> {item_id}. Apps Script 액션은 board_add/update/delete, itemId와 COL 키를 사용한다.
- 반환 항목 id/item_id는 UUID, row는 최신 위치. 썸네일과 헬퍼에도 item_id 전달. 기존 썸네일 요청 형식은 호환하되 ID가 있으면 우선 확인한다.
- 참고 링크/채널 원문 문자열을 별도 반환해 채널의 빈 줄과 여분 줄을 보존한다.

## 검증 및 쓰기
읽기 매핑과 쓰기 허용 목록은 분리한다. 날짜·ID·수식·썸네일 URL은 일반 편집 불가. 체크박스는 JSON boolean만 허용한다. 텍스트는 선행 = 제거, 자르기 전 길이 검사: 요리 제목/채널 200, URL 2000, 원본/영상 제목 500, 참고 링크 5000, 참고 채널 2000, 설명/고정 댓글 20000, 메모 5000자. 빈 수정 요청은 거절하되 동일 값 요청은 성공한다.
최종 상태가 업로드 완료일 때만 플랫폼 값 입력 가능하고 비우기는 허용한다. 상태 변경만으로 기존 플랫폼 값을 삭제하지 않는다.
링크 변경 시 자동 채움이 우선한다. 빈 링크는 메타데이터를 비운다. 조회 실패 시 입력값을 보존하고 경고한다. 쓰기 후 레퍼 동기화 실패도 저장 실패와 구별한다. 통신 오류 시 추가·삭제는 자동 재시도하지 않는다.

## CSV 지연과 화면
연결 시트와 UUID별 변경 전후 상태/작업 순서를 180초 보관한다. 연속 추가·수정·삭제와 썸네일 변경을 함께 재생하며 CSV에서 관찰된 작업만 제거한다. 구조 변경에 이전 기록을 초기화하지 않는다. 미반영 삽입/삭제만 위치를 보정한다. 연결 변경/해제 시 기록을 초기화한다. 같은 로컬 서버의 쓰기와 연결 변경은 직렬화해 응답 순서가 작업 순서를 뒤집지 않게 한다.
편집 DOM과 커서는 폴링·정렬·필터 변경에도 유지한다. 조회 순서와 쓰기 세대로 오래된 응답을 무시한다. 저장 중 입력/중복 제출을 막는다. 외부 삭제 시 입력을 보존하고 저장 불가 안내를 표시한다. dirty 확인, Esc, Ctrl/Cmd+Enter, beforeunload, 변경 방송을 제공한다. 수정 필드만 전송하며 같은 필드의 동시 수정은 마지막 성공 쓰기를 적용한다.

## 버전과 검증
UPLOAD_VERSION은 기존 9에서 10으로 올린다. 글자수 수식 복구는 현황판 삽입/삭제 경로(후보/레퍼 연동 포함)에만 적용한다.
Python 전체 테스트, JS 레퍼 레이아웃 테스트, Apps Script 모의 테스트, 프론트엔드 로컬 테스트로 검증한다. ID 이전/중복/행 이동, 플랫폼 잠금, 수식 복구, 원문 보존, 길이 초과, 연속 변경/부분 CSV 반영/썸네일 교차/시트 전환, 오래된 조회 응답을 포함한다.
사용자 적용 순서: Code.gs 교체 → setupSheets → 새 버전 배포 → version 10 확인 → 새로고침. 브라우저에서 연속 빈 행 추가, 행 이동 후 수정/삭제, 자동 채움, 플랫폼 잠금, 폴링 중 폼 유지, 두 탭 갱신, 썸네일을 확인한다.
