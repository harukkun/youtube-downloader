# 쇼츠 현황판 — 구글 스프레드시트 버전

쇼츠 현황판의 **데이터 저장소**입니다. 링크만 공유하면 누구나(또는 지정한 사람만) 휴대폰·PC에서 바로 쓸 수 있고,
동시 편집과 변경 기록은 시트가 알아서 해 줍니다. 로컬 앱의 웹 현황판(`/shorts`)은 이 시트를 읽어서 보여 주는 뷰어로 동작합니다
(연결 방법은 [../README.md](../README.md)의 쇼츠 현황판 항목). 자동화(링크 붙이면 제목·채널 채우기,
상태에 따른 플랫폼 입력 잠금, 썸네일 업로드 수신)는 [Code.gs](Code.gs)의 Apps Script(자바스크립트)가 담당합니다.

## 처음 한 번 설정 (5분)

1. 구글 드라이브에서 **새 스프레드시트**를 만들고 이름을 정합니다 (예: `쇼츠 현황판`).
2. 메뉴 **확장 프로그램 › Apps Script** 를 엽니다. 편집기에 기본으로 있는 `function myFunction() {}` 내용을 지우고
   [Code.gs](Code.gs) 파일 내용을 전부 붙여 넣은 뒤 저장(⌘S)합니다.
3. 편집기 상단 도구막대의 함수 선택 상자에서 **`setupSheets`** 를 고르고 **▶ 실행**을 누릅니다.
4. 권한 승인 창이 뜹니다. 계정을 고르고, "확인되지 않은 앱" 경고가 나오면 **고급 › (프로젝트 이름)(안전하지 않음)으로 이동**
   → **허용**. 요청 권한은 두 가지입니다: 스프레드시트 편집, 외부 서비스 연결(유튜브 정보 조회용).
5. 스프레드시트 탭으로 돌아오면 **현황판**·**요약** 시트와 상단 **쇼츠 현황판** 메뉴가 생겨 있습니다.
   (메뉴가 안 보이면 페이지를 새로고침합니다.)

`setupSheets`는 몇 번 실행해도 안전합니다. 헤더·서식·드롭다운·조건부 서식·트리거만 다시 만들고 입력한 데이터는 건드리지 않습니다.
시트에서 열을 드래그해 순서를 바꿔 두었다면 실행 시 헤더 이름을 보고 열을 코드의 표준 순서로 **되돌립니다**(데이터는 열과 함께 이동).
코드에 없는 열을 직접 추가했다면 표준 열 뒤로 밀리고 지워지지는 않습니다.
이전 버전으로 만든 시트(열 이름이 1행에 있고, 설명 글자수 열이 있고, 상태에 이모지가 없는 배치)도 다시 실행하면
새 배치로 자동으로 옮겨집니다. 예전 버전이 F열에 자동으로 넣던 **원본 영상 썸네일 수식은 이때 한 번 비워집니다**
(F열은 이제 내가 만든 쇼츠 썸네일 자리입니다. 아래 "웹 앱 배포" 참고).

## 디자인

- 1행은 열 그룹 띠(📋 기본 · 🎬 원본 영상 · 🔎 참고 쇼츠 · 🚀 업로드 플랫폼 · ✍️ 내 영상 정보 · 🗂️ 기타), 2행은 열 이름입니다. 그룹마다 색이 다르고 열 이름은 같은 색의 연한 톤입니다.
- 데이터는 3행부터. 격자선을 숨기고 줄무늬 배경과 얇은 가로선만 써서 표가 가볍게 보입니다.
- 상태는 이모지가 붙은 칩 색(⭐ 보라 · ⬜ 회색 · 🎬 파랑 · ⏳ 노랑 · ✅ 초록), 체크된 플랫폼은 초록, 잠긴 플랫폼은 회색, 100자를 넘은 제목 글자수는 빨강으로 표시됩니다.
- 상태 열의 필터 버튼에서 촬영 후보·촬영 중·편집 중 등 하나 이상의 상태만 골라 볼 수 있습니다. 전체 선택으로 필터를 해제합니다.
- 레퍼 체크에서 촬영 후보로 승격하면 쇼츠 제목은 `요리 제목`, 링크와 채널은 `참고 쇼츠 링크`·`참고 채널`에 저장됩니다.
- 색·이모지·열 이름은 `Code.gs` 위쪽의 `STATUSES`, `PLATFORMS`, `COLUMNS`, `GROUPS`, `PALETTE`에서 바꿀 수 있습니다. 바꾼 뒤 **시트 초기 설정**을 다시 실행하면 적용됩니다.

## 시트 구성

1·2행은 헤더(그룹 띠 + 열 이름), 데이터는 **3행부터**입니다.

| 열 | 내용 | 비고 |
|---|---|---|
| A 📌 상태 | 드롭다운: ⭐ 촬영 후보 → 🎬 촬영 중 → ✂️ 편집 중 → ⏳ 업로드 대기 → ✅ 업로드 완료 | 상태별 색 자동 · 헤더 필터 제공. 예전 라벨은 `setupSheets` 를 다시 실행하면 새 라벨로 바뀝니다(후보·제작 전 → 촬영 후보, 제작 중 → 촬영 중, 제작 완료·업로드 대기 → 업로드 대기) |
| B 🍳 요리 제목 | 예: `어남선생-남원찜닭` | 처음 입력하면 W열 등록일이 찍힘 |
| C 🔗 원본 링크 | 재가공 소재가 되는 유튜브 영상 | 붙이면 D·E 자동 채움 |
| D·E 원본 제목·채널 | 자동 | |
| F 🖼️ 썸네일 | **내가 재가공한 쇼츠의 썸네일** (셀 안 이미지) | 웹 현황판(`/shorts`)의 없음 버튼 → 이미지 첨부, 또는 업로드 헬퍼의 썸네일 만들기에서 등록. 시트에서 직접 넣으려면 `=IMAGE("https://…")` |
| G 🔍 참고 쇼츠 링크 | 같은 요리를 다룬 다른 채널 쇼츠. 여러 개는 **줄바꿈**(⌥⏎ / Alt+Enter)으로 한 줄에 하나 | 채우면 H 자동 |
| H 👥 참고 채널 | 자동, G와 같은 순서 | |
| I~P 🚀 플랫폼 | ▶️ 유튜브 · 📸 인스타그램 · 🎵 틱톡 · 🟢 네이버 클립 각각 **체크박스 + 내 업로드 링크** | **상태가 ✅ 업로드 완료일 때만 입력 가능**. 그 외 상태에서는 회색으로 표시되고 입력하면 되돌려짐 |
| Q ✏️ 영상 제목 / R 🔢 글자수 | 100자 초과 시 R이 빨갛게 | |
| S 📝 설명 | 유튜브 설명란 텍스트 | 긴 글은 셀을 더블클릭해 편집하거나 수식 입력줄(위쪽 fx 칸)을 넓혀서 편집 |
| T 💬 고정 댓글, U 🗒️ 메모 | 자유 입력 | |
| V 🕒 수정일, W 📅 등록일 | 자동 | |
| X 🔗 썸네일 링크 | 자동 · **숨김 열** | F열 이미지의 URL(텍스트). `IMAGE()` 수식은 CSV로 내보내면 빈 칸이 되기 때문에 웹 현황판은 이 열을 읽습니다. 직접 고치지 마세요 |

**요약** 시트: 상태별 개수, 전체 항목 수, 플랫폼별 업로드 개수. 전부 수식이라 자동으로 바뀝니다.

**레퍼 채널** · **레퍼 쇼츠** 시트: 로컬 앱의 **레퍼 체크**(`/references`)가 팀 동기화용으로 쓰는 탭입니다.
`setupSheets`가 만들고, 이후에는 각 팀원의 로컬 앱이 웹 앱(doPost)을 통해 읽고 씁니다. 1행이 헤더, 2행부터 데이터입니다.

**레퍼 채널** — 등록한 유튜브 채널 한 줄씩. 사람이 보는 탭이라 보기 좋게 꾸며져 있습니다.

| 열 | 내용 | 비고 |
|---|---|---|
| A 🖼️ 프로필 | 채널 프로필 이미지 | `IMAGE()` 수식. 원본 URL은 숨김 열 G |
| B 📺 채널 | 채널 이름 | 클릭하면 유튜브 채널로 이동(셀에 링크) |
| C 👥 구독자 | 구독자 수 | 숫자, 천 단위 쉼표 |
| D 📅 추가 시각 | 레퍼 체크에 등록한 시각 | 날짜 값 |
| E 📦 쇼츠 목록 | 쇼츠 목록 수집 상태 | ✅ 완료 · ⏳ 진행 중 · ➖ 미분석 (상태별 색) |
| F 🕒 분석 저장 시각 | 마지막으로 분석 결과를 저장한 시각 | 날짜 값 |
| G 🔗 프로필 이미지 URL · H 📝 채널 설명 | 앱이 쓰는 값 | **숨김 열**. 레퍼 체크 상세 화면의 이미지·설명에 쓰입니다 |
| I 🆔 채널 ID | 유튜브 채널 ID | 앱이 행을 찾는 키 |

헤더의 **▼ 필터 버튼**으로 구독자 순, 추가 시각 순 등으로 정렬할 수 있습니다. 앱은 행 번호가 아니라 채널 ID로 행을 찾기 때문에 정렬해도 동기화에 영향이 없습니다.
이전 배치(채널 ID가 첫 열, URL·설명이 보이는 배치)로 만든 탭은 `setupSheets`를 다시 실행하면 데이터를 그대로 옮겨 새 배치로 바꿉니다.

**레퍼 쇼츠** — 채널의 쇼츠 한 줄씩. 레퍼 채널과 같은 디자인이며 헤더 ▼ 필터로 조회수·좋아요·댓글 순 정렬이 됩니다.

| 열 | 내용 | 비고 |
|---|---|---|
| A 🖼️ 썸네일 | 영상 썸네일 이미지 | `IMAGE()` 수식. 원본 URL은 숨김 열 N |
| B 🎬 제목 | 영상 제목 | 클릭하면 유튜브 쇼츠로 이동 |
| C 👁️ 조회수 · D 👍 좋아요 · E 💬 댓글 | 숫자 | 상세 수집 전에는 좋아요·댓글이 비어 있음 |
| F 📅 업로드일 | 날짜 값 | |
| G 🔎 상세 상태 | ✅ 분석 완료 · ⏳ 상세 대기 · ➖ 50만 미만 · ⚠️ 조회 실패 | 로컬 앱의 수집 단계 |
| H 📌 현황판 | **현황판 탭에서 이 영상의 상태** (⭐ 촬영 후보 · 🎬 촬영 중 …, 미등록이면 빈 칸) | 아래 "현황판과 동기화" 참고 |
| I 📍 고정 댓글 · J ✍️ 작성자 · K 📝 설명 · L ⚠️ 상세 오류 · M 🕒 동기화 시각 | | |
| N 🔗 썸네일 URL | 앱이 쓰는 값 | **숨김 열** |
| O 📺 채널 ID · P 🎞️ 영상 ID | 앱이 행을 찾는 키 | |

**현황판과 동기화 (H열)**
- 빈 칸을 드롭다운에서 **⭐ 촬영 후보**로 바꾸면 현황판 맨 위에 후보 행이 생깁니다(요리 제목 = 영상 제목, 참고 쇼츠 링크·참고 채널 자동). 다시 비우면 후보 행이 지워집니다.
- 이 탭에서 할 수 있는 것은 촬영 후보 지정/해제뿐입니다. 다른 단계를 고르면 되돌리고 안내가 뜨며, 현황판에서 이미 🎬 촬영 중 이후 단계로 넘어간 영상은 여기서 해제할 수 없습니다.
- 현황판 탭에서 상태·참고 쇼츠 링크·원본 링크를 고치거나, 레퍼 체크 웹에서 후보를 등록/해제하면 이 열에 바로 반영됩니다(편집 트리거). 현황판 행을 통째로 지운 경우처럼 트리거가 못 잡는 변경은 로컬 앱이 그 채널을 다시 열 때 맞춰집니다.

같은 시트·웹 앱·토큰을 저장한 로컬 앱들은 모두 같은 채널 목록을 보고, 한 사람이 분석한 쇼츠 결과를 다른 사람은 다시 수집하지 않고 그대로 이어받습니다.
**값은 직접 고치지 마세요.** 행을 지우거나 열을 옮기면 로컬 앱이 그 채널의 결과를 다시 수집하거나 잘못 읽을 수 있습니다. 정렬(필터)만 자유롭게 쓰면 됩니다.

## 메뉴 (쇼츠 현황판)

| 항목 | 하는 일 |
|---|---|
| 시트 초기 설정 | 위 구조를 (다시) 만듭니다. 열 너비나 서식을 망쳤을 때 실행 |
| 선택한 행 정보 다시 가져오기 | 선택한 행들의 원본 제목·채널과 참고 채널을 **덮어써서** 다시 조회 (썸네일 열은 건드리지 않음) |
| 빈 정보 모두 채우기 | 링크는 있는데 정보가 **비어 있는** 행만 채움. 여러 행을 한 번에 붙여 넣은 뒤 실행 |
| 🔑 썸네일 업로드 연결 정보 | 웹 앱 URL과 업로드 토큰을 보여 줍니다(토큰이 없으면 만듭니다). 로컬 앱 현황판의 "썸네일 업로드 설정"에 붙여 넣습니다 |
| ♻️ 업로드 토큰 다시 만들기 | 토큰이 새어 나갔을 때. 기존 토큰은 즉시 무효가 되고 로컬 앱에 새 토큰을 다시 저장해야 합니다 |

수식으로 쓰고 싶으면 `=YT_META(C3)` 도 됩니다 (원본 제목·채널·원본 썸네일 URL 3칸 반환).

## 웹 앱 배포 (썸네일 업로드 · 촬영 후보 등록 · 레퍼 체크 동기화)

로컬 앱에서 재가공 썸네일을 시트에 넣거나, 레퍼 체크에서 촬영 후보를 등록하거나, 레퍼 채널·분석 결과를 팀과 동기화하려면
이 스크립트를 **웹 앱**으로 한 번 배포해야 합니다. 이미지는
`로컬 앱 → 웹 앱(doPost) → 내 구글 드라이브의 "쇼츠 현황판 썸네일" 폴더(링크가 있는 사용자 보기 가능) → 시트 F열 IMAGE() 수식` 순서로 저장됩니다.
외부 서비스나 API 키는 필요 없고, 내 구글 계정만 씁니다.

1. Apps Script 편집기에서 최신 [Code.gs](Code.gs)를 붙여 넣고 저장한 뒤 **`setupSheets`를 한 번 더 실행**합니다.
   드라이브 권한이 새로 필요하면 승인 창이 다시 뜹니다(고급 › 이동 › 허용). 이때 숨김 열 X가 만들어지고 예전 원본 썸네일 수식이 비워지며,
   내 드라이브에 `쇼츠 현황판 썸네일` 폴더가 생깁니다. 승인 창 없이 끝났는데 폴더가 생겼다면 드라이브 권한은 이미 있는 것이니 그대로 진행하면 됩니다.
   폴더가 안 생기고 "권한이 없습니다" 오류가 나면 편집기 왼쪽 **프로젝트 설정 › appsscript.json 매니페스트 표시**를 켜고
   `oauthScopes`에 `https://www.googleapis.com/auth/drive` 가 있는지(있다면 목록에 추가) 확인하세요.
2. 오른쪽 위 **배포 › 새 배포** → 유형 선택(⚙️) **웹 앱** → 설명 아무거나, **다음 사용자 인증 정보로 실행: 나**,
   **액세스 권한이 있는 사용자: 모든 사용자** → **배포**. 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
   ("모든 사용자"여도 아래 토큰이 맞는 요청만 처리합니다.)
3. 스프레드시트로 돌아와 메뉴 **쇼츠 현황판 › 🔑 썸네일 업로드 연결 정보**를 열면 웹 앱 URL과 **업로드 토큰**이 보입니다.
4. 로컬 앱의 **쇼츠 현황판**(`/shorts`) 페이지 → 시트 연결 카드 아래 **썸네일 업로드 설정**을 펼쳐 URL과 토큰을 붙이고 **저장**.
   서버가 웹 앱에 ping 을 보내 토큰까지 확인한 뒤 `~/.youtube-downloader/config.json`에 저장합니다.
5. 이후 현황판의 **없음** 버튼(또는 기존 썸네일 클릭) → **이미지 첨부** / **썸네일 만들기 →** 로 등록합니다.

**코드를 고친 뒤에는** 배포 › **배포 관리** › 연필(편집) › 버전 **새 버전** › 배포를 눌러야 웹 앱에 반영됩니다(URL은 그대로).
"새 배포"를 만들면 URL이 바뀌어 로컬 앱에 다시 저장해야 합니다.

**레퍼 체크 팀 동기화를 켜려면** 위 1번(최신 `Code.gs` + `setupSheets` 재실행 → `레퍼 채널`·`레퍼 쇼츠` 탭 생성)과
새 버전 배포를 마친 뒤, **팀원 각자** 자기 로컬 앱의 `/shorts`에 같은 시트 링크와 같은 웹 앱 URL·토큰을 저장하면 됩니다.
토큰은 시트 편집 권한과 같으니 팀 안에서만 전달하세요. 동기화가 안 되면 `/references` 상단의 상태 문구에 이유가 표시됩니다.

브라우저에서 웹 앱 URL을 열면 `{"ok":true,"service":"shorts-thumbnail",…}` 가 보여야 정상입니다.

## 기존 웹 현황판 데이터 옮기기

`~/.youtube-downloader/shorts.json` 에 있던 항목은 1건이라 그대로 입력하면 됩니다.

| 열 | 값 |
|---|---|
| 상태 | ✅ 업로드 완료 |
| 요리 제목 | 어남선생-남원찜닭 |
| 원본 링크 | https://www.youtube.com/watch?v=kRl5OlSq7Sw&t=2s |
| 참고 쇼츠 링크 | https://www.youtube.com/shorts/Sl2soHoPCs8 (87아빠) ⏎ https://www.youtube.com/shorts/8bQHN3UDCSk (쉽게쿡쿡) |
| 영상 제목 | 어남선생(류수영) 만원찜닭 레시피 #kfood |

원본 링크와 참고 쇼츠 링크를 붙이면 나머지(원본 제목·채널, 참고 채널)는 자동으로 채워집니다.
썸네일은 웹 현황판의 없음 버튼 → 이미지 첨부로 올립니다(위 "웹 앱 배포" 참고). 시트의 **삽입 › 이미지 › 셀에 이미지 삽입**으로
넣은 그림은 시트에서는 보이지만 CSV로 내보내지지 않아 웹 현황판에는 나오지 않습니다.

## 공유

오른쪽 위 **공유** → 일반 액세스를 **링크가 있는 모든 사용자**로 바꾸고 권한을 **편집자**(함께 고칠 사람) 또는
**뷰어**(보기만)로 고른 뒤 링크를 전달합니다. 특정 사람만 편집하게 하려면 그 사람의 이메일을 편집자로 추가하고
링크 권한은 뷰어로 두면 됩니다.

## 휴대폰에서 새 항목 등록 (선택)

시트 메뉴 **도구 › 새 양식 만들기**로 구글 폼을 연결하면 폼 응답이 새 시트("설문지 응답 1")에 쌓입니다.
현황판 시트에 바로 들어오게 하려면 폼 질문을 현황판 열 순서(요리 제목, 원본 링크, 참고 쇼츠 링크 …)와 맞추고,
응답 시트에서 현황판으로 복사해 붙이는 방식이 가장 단순합니다. 자동 이동이 필요해지면 그때 스크립트를 한 줄 더 추가하면 됩니다.

## 업로드 헬퍼와 함께 쓰기

설명 텍스트는 로컬 앱의 **업로드 헬퍼**(`http://127.0.0.1:8765/helper`)에서 만들고 **결과 복사**로 복사한 뒤,
현황판의 **설명(S열)** 셀을 더블클릭해 붙여 넣습니다. 헬퍼 화면의 글자수 카운터로 5000자 이내인지 확인하면 됩니다.

## 문제 해결

**링크를 붙여도 자동으로 채워지지 않는다**
`setupSheets`가 만든 편집 트리거가 없는 경우입니다. 메뉴 **쇼츠 현황판 › 시트 초기 설정**을 다시 실행하세요.
Apps Script 편집기 왼쪽 **트리거(시계 아이콘)** 에서 `handleEdit` 항목이 있는지 확인할 수 있습니다.

**특정 링크만 채워지지 않는다**
비공개·삭제·연령 제한 영상은 유튜브가 정보를 주지 않습니다. 재생목록 링크도 안 됩니다. 영상 링크(`watch?v=` 또는 `shorts/`)를 넣어 주세요.

**여러 줄 셀을 복사해 다른 앱에 붙이면 앞뒤에 따옴표가 붙는다**
셀을 선택해서 복사하면 스프레드시트가 줄바꿈이 있는 값을 따옴표로 감쌀 때가 있습니다.
셀을 **더블클릭해 편집 상태에서 전체 선택(⌘A) → 복사**하면 따옴표 없이 복사됩니다.

**권한 승인 때 "이 앱은 Google에서 확인하지 않았습니다"가 뜬다**
본인이 만든 스크립트라서 뜨는 안내입니다. **고급 › 이동 › 허용**으로 진행하면 됩니다.

**`setupSheets` 를 실행한 뒤 헤더와 데이터가 어긋났다 (틱톡 열에 날짜, 영상 제목에 TRUE, 웹 현황판에 항목이 수백 개)**
열 순서를 드래그로 바꿔 둔 시트에 예전 `Code.gs`(열 순서를 맞추지 않던 버전)로 초기 설정을 실행하면 헤더만 표준 순서로 다시 써져 생기는 현상입니다.
**파일 › 버전 기록 › 버전 기록 보기**에서 초기 설정을 실행하기 직전 버전을 골라 **이 버전 복원**을 누른 뒤,
최신 `Code.gs`를 붙여 넣고 `setupSheets`를 다시 실행하세요(이번에는 열을 데이터와 함께 표준 순서로 옮깁니다).
버전 복원은 스크립트 속성(토큰·폴더)과 웹 앱 배포에는 영향이 없습니다. 복원 이후에 올렸던 썸네일만 다시 등록하면 됩니다.

**`setupSheets` 실행 로그에 `Exception: 제작 전 → 제작 중 → …` 같은 상태 라벨 목록이 뜬다**
예전 버전의 상태 드롭다운 규칙(잘못된 값 거부)이 다른 열에 남아 있어 셀 쓰기가 거부된 경우입니다. 최신 `Code.gs`는 초기 설정 때
데이터 영역의 검증 규칙을 먼저 지우고 다시 만들므로, 최신 코드를 붙여 넣고 `setupSheets`를 다시 실행하면 해결됩니다.

**썸네일 업로드 설정 저장 시 "웹 앱이 로그인 페이지를 돌려줬습니다"**
배포의 액세스 권한이 "모든 사용자"가 아니거나 실행 계정이 "나"가 아닙니다. 배포 관리에서 고치고 새 버전으로 배포하세요.

**"토큰이 맞지 않습니다"**
시트 메뉴 🔑 에 보이는 토큰과 로컬 앱에 저장한 값이 다릅니다. 토큰을 다시 만들었다면 로컬 앱에도 다시 저장해야 합니다.

**레퍼 체크에 "Apps Script를 최신 버전으로 업데이트해 주세요" / "시트 동기화 실패"가 뜬다**
시트에 붙어 있는 `Code.gs`가 레퍼 동기화(`reference_*` 액션)를 모르는 예전 버전입니다. 최신 `Code.gs`를 붙여 넣고 `setupSheets`를 실행한 뒤
배포 관리에서 **새 버전**으로 배포하세요. 웹 앱 URL을 브라우저로 열었을 때 `"version":8` 이상이면 반영된 상태입니다.
동기화가 실패해도 채널 추가·분석은 이 PC의 파일에 그대로 저장되며, 연결이 복구되면 다음 분석 때 시트로 올라갑니다.

**업로드는 됐다는데 시트 F열에 이미지가 안 보인다 / 웹에 깨진 그림이 뜬다**
드라이브 파일의 "링크가 있는 모든 사용자" 공유가 회사(Workspace) 정책으로 막힌 경우입니다. 드라이브에서 `쇼츠 현황판 썸네일` 폴더의 파일 공유 설정을 확인하세요.
개인 구글 계정에서는 문제없습니다. 반영이 몇 초 늦을 수는 있습니다.

**"시트의 행이 바뀌었습니다"**
현황판 화면을 본 뒤 시트에서 행을 끼워 넣거나 지워서 번호가 밀린 경우입니다. 스크립트가 원본 링크(없으면 요리 제목)로 행을 다시 찾지만,
같은 링크의 행이 둘 이상이면 어느 행인지 알 수 없어 거절합니다. 현황판을 새로고침한 뒤 다시 시도하세요.
