# 유튜브 다운로더 (YouTube Downloader)

유튜브 링크를 붙여넣으면 다운로드 가능한 화질 목록을 보여주고, 선택한 화질 또는 mp3 오디오로
원하는 폴더에 저장하는 **로컬 웹 앱**입니다. Python(Flask) 서버가 `yt-dlp`와 `ffmpeg`를 호출하고,
브라우저에서 모든 조작을 합니다. 외부 서버로 데이터가 나가지 않습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 화질 선택 다운로드 | 영상에 존재하는 해상도(예: 2160p60 · 1080p60 · 720p · 480p …)를 목록으로 보여주고 선택해서 mp4로 저장 |
| 오디오만 추출 | 192kbps mp3로 변환해서 저장 |
| 진행률 표시 | 다운로드 %, 속도, 남은 시간, 병합/변환 단계 표시 |
| 저장 위치 선택 | 경로 직접 입력 또는 macOS 폴더 선택 창으로 지정. 사용자 계정별로 기억 |
| 폴더 열기 | 완료 후 Finder에서 저장된 파일이 선택된 상태로 열기 |
| 다운로드 내역 | 받은 영상 목록, 파일 존재 여부, 저장 경로, 크기, 시각 표시. 다시 받기 / 기록 삭제 |
| 쇼츠 현황판 | 구글 시트에 있는 재가공 쇼츠 제작 현황을 읽어 보여 주는 뷰어. 상태 칩 필터, 검색·정렬, 썸네일 미리보기, 복사 버튼. 데이터 편집은 시트에서 ([sheets/README.md](sheets/README.md)) |
| 업로드 헬퍼 | 유튜브 업로드에 필요한 텍스트를 Claude로 만드는 도구 모음. 첫 기능: 다른 채널의 레시피 설명을 내 채널 템플릿 형식으로 변형 |

## 요구 사항

- macOS (Windows/Linux에서도 동작하지만 폴더 선택 창·폴더 열기는 macOS 기준으로 검증됨)
- Python 3.10 이상
- ffmpeg — 영상/오디오 병합과 mp3 변환에 사용

```bash
brew install ffmpeg
```

## 설치 및 실행

```bash
./run.sh
```

처음 실행하면 `.venv` 가상환경을 만들고 `flask`, `yt-dlp`를 설치합니다.
서버가 뜨면 브라우저에 `http://127.0.0.1:8765` 가 자동으로 열립니다. 종료는 터미널에서 `Ctrl+C`.

브라우저를 자동으로 열지 않으려면:

```bash
./run.sh --no-browser
```

수동으로 실행하려면:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

## 사용법

1. **저장 위치** 확인 (기본 `~/Downloads`). 바꾸려면 경로를 입력하고 **저장**, 또는 **폴더 선택…**
2. 유튜브 링크를 붙여넣고 **조회** (Enter 키도 동작)
3. 썸네일·제목·길이를 확인하고 **화질 선택** 드롭다운에서 원하는 화질 또는 `오디오만 (mp3)` 선택
4. **다운로드** → 진행률 바 확인 → 완료 메시지에 저장된 파일명 표시
5. **📂 폴더 열기** 를 누르면 Finder에서 파일이 선택된 상태로 열립니다
6. 하단 **다운로드 내역**에서 지금까지 받은 영상을 확인합니다

### 저장 위치

- 절대 경로만 허용되며 `~` 는 홈 폴더로 풀립니다 (예: `~/Movies/YouTube`)
- 없는 폴더는 자동으로 만들고, 쓰기 권한이 없으면 오류를 표시합니다
- **폴더 선택…** 창은 서버 프로세스가 띄우기 때문에 다른 창 뒤에 나타날 수 있습니다
- 설정은 `~/.youtube-downloader/config.json` 에 저장되어 다음 실행 때도 유지됩니다

### 다운로드 내역

각 항목에는 상태 배지가 붙습니다.

| 배지 | 의미 |
|---|---|
| ✅ 파일 있음 | 기록된 경로에 파일이 존재함 (크기 함께 표시) |
| ⚠️ 파일 없음 | 파일이 삭제되었거나 다른 곳으로 이동됨 |
| ❌ 실패 | 다운로드 실패 (오류 메시지 표시) |
| ⏳ 진행 중 | 현재 다운로드 중 |

- **폴더 열기**: 파일이 있을 때만 표시
- **다시 받기**: 링크를 입력창에 넣고 자동으로 조회
- **기록 삭제** / **목록 비우기**: 기록만 지우며 실제 파일은 삭제하지 않습니다
- 내역은 `~/.youtube-downloader/history.json` 에 최근 500건까지 저장됩니다

## 쇼츠 현황판 (`/shorts`) — 구글 시트 뷰어

재가공 쇼츠 제작 현황의 **데이터는 구글 스프레드시트**에 있고(설정과 시트 구조는 [sheets/README.md](sheets/README.md)),
이 페이지는 그 시트를 읽어서 보기 좋게 보여 주는 **읽기 전용 뷰어**입니다. 시트는 링크 공유·휴대폰·동시 편집을,
웹 화면은 상태 칩 필터, 검색·정렬, 썸네일 호버 미리보기, 제목·설명·고정 댓글 복사 버튼을 담당합니다.

### 연결
1. 시트를 **공유 › 링크가 있는 모든 사용자**(뷰어 이상)로 바꿉니다. 비공개 시트는 읽을 수 없습니다.
2. **현황판** 탭을 연 상태에서 주소창 링크를 복사해 페이지 위쪽 칸에 붙이고 **연결**을 누릅니다.
   서버가 실제로 읽어 본 뒤 성공하면 `~/.youtube-downloader/config.json`에 저장되고, 다음 실행 때도 유지됩니다.
   링크의 `gid`가 현황판 탭이 아니면 첫 탭으로 한 번 더 시도합니다.

### 화면
- **상태 요약 칩**, **검색·상태·플랫폼 필터**, **헤더 클릭 정렬**: 이전과 같고 필터 상태는 브라우저에 기억됩니다.
- **요리 제목 클릭**: 아래로 펼쳐져 영상 제목(100자 카운터)·설명(5000자 카운터)·고정 댓글·메모가 보이고 각각 **복사** 버튼이 있습니다.
- **플랫폼 아이콘**: 체크된 플랫폼만 색이 켜지고, 내 업로드 링크가 있으면 클릭해 이동합니다.
- **시트에서 편집 ↗**: 해당 행이 선택된 상태로 시트를 새 탭에서 엽니다. 수정은 항상 시트에서 합니다.
- **새로고침**: 시트를 바로 다시 읽습니다. 그 외에는 30초 캐시 뒤 자동으로 최신 데이터를 가져옵니다.
- 썸네일은 원본 링크의 영상 ID로 유튜브 썸네일을 표시합니다. 시트에서 직접 올린 이미지는 웹에 나오지 않습니다.

이전 버전이 저장하던 `~/.youtube-downloader/shorts.json`과 `thumbnails/`는 더 이상 쓰지 않지만 삭제하지 않습니다.

## 유튜브 업로드 헬퍼 (`/helper`)

영상을 올릴 때 필요한 텍스트를 만드는 도구 모음 페이지입니다. 왼쪽 목록에서 기능을 고르고, 오른쪽에서 작업합니다.
기능은 계속 추가할 예정이며, 새 기능은 `helper.html`에 목록 버튼 하나와 `section.panel` 하나를 추가하면 됩니다.

### 기능 1 · 레시피 설명 텍스트 제작

다른 채널의 레시피 설명(재료·분량·조리 순서)을 붙여 넣으면, 사실 정보는 그대로 살리고
**내 채널 템플릿** 형식으로 다시 쓴 설명 텍스트를 만듭니다.

1. **내 채널 템플릿**을 펼쳐 템플릿을 내 채널 형식으로 고치고 **템플릿 저장** (처음 한 번)
   - 그대로 남길 글자(이모지, 구분선, 소제목, 고정 문구)는 그냥 적고
   - 채울 자리는 `{{ 여기에 무엇을 넣을지 설명 }}` 형식으로 적습니다 (예: `{{재료를 "· 재료 분량" 형식으로 한 줄씩}}`)
   - **추가 지시**에는 말투, 제거할 문구 등 채널 고유 규칙을 적습니다
2. 왼쪽 칸에 원본 레시피 설명을 붙여 넣고 **내 템플릿으로 변형 →**
3. 오른쪽 결과를 확인·수정하고 **결과 복사** → 유튜브 설명란에 붙여넣기
   - **⚠ 업로드 전 확인** 상자에는 원본에 없어서 채우지 못한 항목(인분, 시간 등)이 표시됩니다

항상 적용되는 규칙: 원본에 없는 재료·분량·시간은 만들어 넣지 않음, 원본의 채널명·링크·광고 문구 제거,
문장은 다시 쓰되 사실 정보는 유지, 5000자 이내.

### Claude 호출 방식

| 방식 | 조건 | 비고 |
|---|---|---|
| **Claude Code CLI** (기본) | 이 컴퓨터에 `claude` 명령이 설치되어 있고 로그인된 상태 | 구독으로 처리. `claude -p` 를 헤드리스로 실행 |
| **Anthropic API** | `ANTHROPIC_API_KEY` 환경 변수 + `anthropic` 패키지 (`.venv/bin/pip install anthropic`) | 사용량 과금 |

모델은 Sonnet(빠름, 기본)과 Opus(품질 우선) 중 선택합니다. 한 번 변형에 보통 10~40초 걸립니다.

### 저장 위치
```
~/.youtube-downloader/
└── helper.json           템플릿, 추가 지시, 모델·호출 방식
```
원본 텍스트 입력칸은 브라우저(localStorage)에만 임시 보관됩니다.

## 문제 해결

**다운로드가 갑자기 실패한다**
유튜브 측 변경으로 yt-dlp가 동작하지 않는 경우가 대부분입니다. 최신 버전으로 업데이트하세요.

```bash
.venv/bin/pip install -U yt-dlp
```

**`Address already in use` / 포트 8765 충돌**
이미 서버가 떠 있는 상태입니다. 기존 터미널에서 `Ctrl+C` 로 종료하거나 아래로 확인합니다.

```bash
lsof -nP -iTCP:8765 -sTCP:LISTEN
```

**ffmpeg 관련 오류**
`brew install ffmpeg` 로 설치했는지, 터미널에서 `ffmpeg -version` 이 실행되는지 확인하세요.

**QuickTime에서 "일부 미디어가 호환되지 않습니다" 경고가 뜬다**
영상 코덱이 VP9 또는 AV1인 파일입니다. Apple 기본 앱은 H.264/HEVC만 재생합니다.
현재 버전은 H.264를 우선 선택하므로 다시 다운로드하면 해결되고, 4K처럼 H.264가 없는 화질은
VLC·IINA로 재생하거나 `ffmpeg -i in.mp4 -c:v libx264 -crf 18 -c:a copy out.mp4` 로 변환하세요.

**연령 제한 / 비공개 / 멤버십 영상**
로그인이 필요한 영상은 지원하지 않습니다.


## API

프론트엔드가 사용하는 로컬 API입니다. 서버는 `127.0.0.1` 에만 바인딩됩니다.

| 메서드 | 경로 | 설명 |
|---|---|---|
| `POST` | `/api/info` | `{url}` → 제목, 썸네일, 길이, 화질 목록 |
| `POST` | `/api/download` | `{url, quality, title?, thumbnail?, quality_label?}` → `{job_id}` (백그라운드 시작) |
| `GET` | `/api/progress/<job_id>` | 진행 상태 (`status`, `percent`, `speed`, `eta`, `filename` …) |
| `POST` | `/api/open-folder` | `{job_id}` 또는 `{history_id}` → Finder에서 파일 위치 열기 |
| `GET` | `/api/settings` | 현재 저장 위치 |
| `POST` | `/api/settings` | `{download_dir}` → 저장 위치 변경 (검증 후 저장) |
| `POST` | `/api/choose-folder` | OS 폴더 선택 창 → 선택한 경로로 변경, 취소 시 `{cancelled: true}` |
| `GET` | `/api/history` | 다운로드 내역 (파일 존재 여부·크기 포함) |
| `DELETE` | `/api/history/<id>` | 기록 하나 삭제 |
| `DELETE` | `/api/history` | 기록 전체 삭제 |
| `GET` | `/api/shorts` | 시트를 읽어 항목 목록 + 상태·플랫폼 정의 + 연결 정보. `?refresh=1`이면 캐시 무시. 읽기 실패 시 `error`와 마지막 캐시 |
| `GET` | `/api/shorts/sheet` | 연결된 시트 정보 |
| `POST` | `/api/shorts/sheet` | `{url}` → 시트 링크 저장(읽기 검증 후). 빈 값이면 연결 해제 |
| `GET` | `/api/helper/settings` | 헬퍼 설정(레시피 템플릿·모델·호출 방식) + 기본값 + 환경(CLI/API 키 유무) |
| `PUT` | `/api/helper/settings` | `{recipe: {template, instructions, model, backend}}` → 보낸 필드만 저장 |
| `POST` | `/api/helper/recipe-description` | `{source_text, template?, instructions?, model?, backend?}` → `{description, notes, usage}` (설정 미전송 시 저장값 사용, 저장하지 않음) |

`quality` 값은 세로 해상도 숫자(`"1080"`, `"720"` …) 또는 `"audio"` 입니다.
영상은 **H.264(avc1) 코덱을 최우선**으로 골라 `bestaudio` 와 mp4로 병합하고, 오디오는 `bestaudio` 를 mp3로 변환합니다.
해당 해상도에 H.264가 없을 때만(주로 4K 이상) VP9/AV1로 넘어가며, 이 경우 화질 목록에 `⚠ VP9/AV1 (QuickTime 재생 불가)` 가 표시됩니다.

## 참고

- 유튜브 재생목록 링크를 넣으면 첫 번째 영상만 처리합니다.
- 파일명은 영상 제목 그대로 저장되며(`제목.mp4`), 같은 이름이 있으면 덮어씁니다.
- 개인 소장 목적으로만 사용하세요. 저작권이 있는 콘텐츠의 재배포는 금지됩니다.

## 쇼츠 썸네일 만들기

상단 **썸네일 만들기** 메뉴 또는 `/thumbnail`에서 사용할 수 있습니다.

1. MOV·MP4 영상 또는 PNG·JPG·WebP 이미지를 선택하거나 드래그합니다. 이미지는 바로 배경으로 적용됩니다. 브라우저에서만 처리하며 서버로 업로드하지 않습니다.
2. 재생/일시정지와 타임라인 또는 ±0.1초 버튼으로 탐색한 뒤 **이 장면 사용**을 누릅니다.
3. 서브타이틀과 제목(최대 두 줄)을 입력하고 크기·위치를 조정합니다. 크기는 슬라이더 또는 px 숫자로 입력합니다(24–320px). 가로·세로 위치도 슬라이더 또는 % 숫자로 입력합니다(5–95%). CookieRun Bold를 사용하고 서브타이틀·제목의 글자색과 외곽선 색을 각각 선택할 수 있으며(기본 흰색/검정) 긴 문구는 자동 축소됩니다.
4. 미리보기 배경을 드래그하거나 확대 비율을 슬라이더 또는 숫자로 조정해(100–300%) 9:16 구도를 맞춥니다.
5. PNG 또는 JPG(품질 100%)로 저장합니다. 두 형식 모두 1080 × 1920이며 미리보기와 동일한 Canvas에서 출력합니다.

브라우저에서 지원하지 않는 코덱은 MP4(H.264/AAC)로 변환해야 합니다. 작업은 새로고침 시 초기화됩니다. 영상 교체 시 선택 장면은 초기화되지만 문구와 타이포 설정은 유지됩니다. 폰트 파일은 `static/fonts/CookieRun-Bold.otf`에서 제공하며, 로드 실패 시 페이지의 재시도 버튼을 사용할 수 있습니다.
