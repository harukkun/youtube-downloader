# 유튜브 다운로더 (YouTube Downloader)

유튜브 링크를 붙여넣으면 다운로드 가능한 화질 목록을 보여주고, 선택한 화질 또는 mp3 오디오로
원하는 폴더에 저장하는 **로컬 웹 앱**입니다. Python(Flask) 서버가 `yt-dlp`와 `ffmpeg`를 호출하고,
브라우저에서 모든 조작을 합니다. 외부 서버로 데이터가 나가지 않습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 화질 선택 다운로드 | 영상에 존재하는 해상도(예: 2160p60 · 1080p60 · 720p · 480p …)를 목록으로 보여주고 선택해서 mp4로 저장 |
| 오디오만 추출 | 192kbps mp3로 변환해서 저장 |
| 진행률 표시 | 다운로드 %, 속도, 남은 시간, 병합/변환 단계 표시 |
| 저장 위치 선택 | 경로 직접 입력 또는 macOS 폴더 선택 창으로 지정. 사용자 계정별로 기억 |
| 폴더 열기 | 완료 후 Finder에서 저장된 파일이 선택된 상태로 열기 |
| 다운로드 내역 | 받은 영상 목록, 파일 존재 여부, 저장 경로, 크기, 시각 표시. 다시 받기 / 기록 삭제 |
| 쇼츠 현황판 | 재가공 쇼츠 제작 현황을 표로 관리. 원본·참고 링크, 상태, 업로드 플랫폼, 제목·썸네일·설명·고정 댓글 |

## 요구 사항

- macOS (Windows/Linux에서도 동작하지만 폴더 선택 창·폴더 열기는 macOS 기준으로 검증됨)
- Python 3.10 이상
- ffmpeg — 영상/오디오 병합과 mp3 변환에 사용

```bash
brew install ffmpeg
```

## 설치 및 실행

```bash
./run.sh
```

처음 실행하면 `.venv` 가상환경을 만들고 `flask`, `yt-dlp`를 설치합니다.
서버가 뜨면 브라우저에 `http://127.0.0.1:8765` 가 자동으로 열립니다. 종료는 터미널에서 `Ctrl+C`.

브라우저를 자동으로 열지 않으려면:

```bash
./run.sh --no-browser
```

수동으로 실행하려면:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

## 사용법

1. **저장 위치** 확인 (기본 `~/Downloads`). 바꾸려면 경로를 입력하고 **저장**, 또는 **폴더 선택…**
2. 유튜브 링크를 붙여넣고 **조회** (Enter 키도 동작)
3. 썸네일·제목·길이를 확인하고 **화질 선택** 드롭다운에서 원하는 화질 또는 `오디오만 (mp3)` 선택
4. **다운로드** → 진행률 바 확인 → 완료 메시지에 저장된 파일명 표시
5. **📂 폴더 열기** 를 누르면 Finder에서 파일이 선택된 상태로 열립니다
6. 하단 **다운로드 내역**에서 지금까지 받은 영상을 확인합니다

### 저장 위치

- 절대 경로만 허용되며 `~` 는 홈 폴더로 풀립니다 (예: `~/Movies/YouTube`)
- 없는 폴더는 자동으로 만들고, 쓰기 권한이 없으면 오류를 표시합니다
- **폴더 선택…** 창은 서버 프로세스가 띄우기 때문에 다른 창 뒤에 나타날 수 있습니다
- 설정은 `~/.youtube-downloader/config.json` 에 저장되어 다음 실행 때도 유지됩니다

### 다운로드 내역

각 항목에는 상태 배지가 붙습니다.

| 배지 | 의미 |
|---|---|
| ✅ 파일 있음 | 기록된 경로에 파일이 존재함 (크기 함께 표시) |
| ⚠️ 파일 없음 | 파일이 삭제되었거나 다른 곳으로 이동됨 |
| ❌ 실패 | 다운로드 실패 (오류 메시지 표시) |
| ⏳ 진행 중 | 현재 다운로드 중 |

- **폴더 열기**: 파일이 있을 때만 표시
- **다시 받기**: 링크를 입력창에 넣고 자동으로 조회
- **기록 삭제** / **목록 비우기**: 기록만 지우며 실제 파일은 삭제하지 않습니다
- 내역은 `~/.youtube-downloader/history.json` 에 최근 500건까지 저장됩니다

## 쇼츠 현황판 (`/shorts`)

원본 요리 영상을 쇼츠로 재가공해 여러 플랫폼에 올리는 작업의 진행 상황을 한눈에 보는 페이지입니다.
메인 화면 오른쪽 위 **쇼츠 현황판 →** 링크로 이동합니다.

### 항목 구성
| 필드 | 내용 |
|---|---|
| 요리 제목 | 예: `어남선생 - 만원찜닭` |
| 원본 영상 링크 | 재가공 소재가 되는 유튜브 영상. **가져오기**를 누르면 제목·채널·썸네일을 자동으로 채움 |
| 참고 쇼츠 | 같은 요리를 다룬 다른 채널의 쇼츠 링크(여러 개). **채널** 버튼으로 채널명 자동 입력 |
| 진행 상태 | 제작 전 → 제작 중 → 제작 완료·업로드 대기 → 업로드 완료 |
| 업로드 플랫폼 | 유튜브 · 인스타그램 · 틱톡 · 네이버 클립 체크박스(표에서는 아이콘만, 편집 패널에서는 아이콘 + 이름). 체크하면 내 업로드 링크(선택) 입력 가능. **진행 상태가 업로드 완료일 때만 입력할 수 있음** |
| 영상 세부 정보 | 제목(100자 카운터), 썸네일(이미지 업로드, 표에서 호버 시 미리보기), Description(5000자 카운터), 고정 댓글 |
| 메모 | 자유 메모 |

### 화면 기능
- **상태 요약 칩**: 상태별 개수 표시, 클릭하면 해당 상태만 필터
- **검색·필터**: 요리 제목/영상 제목/채널 검색, 상태·플랫폼 필터, 헤더 클릭 정렬. 필터 상태는 브라우저에 기억
- **표에서 바로 변경**: 상태 드롭다운과 플랫폼 체크박스는 표에서 바꾸면 즉시 저장 (플랫폼은 업로드 완료 상태에서만 활성화)
- **편집 패널**: 행의 요리 제목이나 **편집**을 클릭하면 오른쪽 패널에서 전체 항목 수정
- **복사 버튼**: 제목·Description·고정 댓글을 클립보드로 복사 (업로드할 때 붙여넣기용)
- **내보내기 / 가져오기**: 전체 목록을 JSON 파일로 백업하고, 다른 PC에서 병합(같은 id는 덮어씀) 또는 교체로 복원

### 저장 위치
```
~/.youtube-downloader/
├── shorts.json           현황판 목록
└── thumbnails/           업로드한 썸네일 (항목 id.확장자)
```
썸네일은 jpg · png · webp, 10MB 이하. 썸네일을 올리지 않으면 원본 영상 썸네일이 대신 표시됩니다.

## 문제 해결

**다운로드가 갑자기 실패한다**
유튜브 측 변경으로 yt-dlp가 동작하지 않는 경우가 대부분입니다. 최신 버전으로 업데이트하세요.

```bash
.venv/bin/pip install -U yt-dlp
```

**`Address already in use` / 포트 8765 충돌**
이미 서버가 떠 있는 상태입니다. 기존 터미널에서 `Ctrl+C` 로 종료하거나 아래로 확인합니다.

```bash
lsof -nP -iTCP:8765 -sTCP:LISTEN
```

**ffmpeg 관련 오류**
`brew install ffmpeg` 로 설치했는지, 터미널에서 `ffmpeg -version` 이 실행되는지 확인하세요.

**QuickTime에서 "일부 미디어가 호환되지 않습니다" 경고가 뜬다**
영상 코덱이 VP9 또는 AV1인 파일입니다. Apple 기본 앱은 H.264/HEVC만 재생합니다.
현재 버전은 H.264를 우선 선택하므로 다시 다운로드하면 해결되고, 4K처럼 H.264가 없는 화질은
VLC·IINA로 재생하거나 `ffmpeg -i in.mp4 -c:v libx264 -crf 18 -c:a copy out.mp4` 로 변환하세요.

**연령 제한 / 비공개 / 멤버십 영상**
로그인이 필요한 영상은 지원하지 않습니다.

## 프로젝트 구조

```
youtube-downloader/
├── app.py                Flask 서버, yt-dlp 다운로드 로직, 설정/내역 저장
├── templates/
│   ├── index.html        다운로더 페이지 (인라인 CSS/JS, 프레임워크 없음)
│   └── shorts.html       쇼츠 현황판 페이지
├── requirements.txt      flask, yt-dlp
├── run.sh                가상환경 생성 + 서버 실행 스크립트
└── .venv/                가상환경 (자동 생성, git 제외 대상)
```

사용자 데이터는 프로젝트 폴더가 아닌 홈 디렉터리에 저장됩니다.

```
~/.youtube-downloader/
├── config.json           저장 위치 설정
├── history.json          다운로드 내역
├── shorts.json           쇼츠 현황판 목록
└── thumbnails/           현황판 썸네일 이미지
```

## API

프론트엔드가 사용하는 로컬 API입니다. 서버는 `127.0.0.1` 에만 바인딩됩니다.

| 메서드 | 경로 | 설명 |
|---|---|---|
| `POST` | `/api/info` | `{url}` → 제목, 썸네일, 길이, 화질 목록 |
| `POST` | `/api/download` | `{url, quality, title?, thumbnail?, quality_label?}` → `{job_id}` (백그라운드 시작) |
| `GET` | `/api/progress/<job_id>` | 진행 상태 (`status`, `percent`, `speed`, `eta`, `filename` …) |
| `POST` | `/api/open-folder` | `{job_id}` 또는 `{history_id}` → Finder에서 파일 위치 열기 |
| `GET` | `/api/settings` | 현재 저장 위치 |
| `POST` | `/api/settings` | `{download_dir}` → 저장 위치 변경 (검증 후 저장) |
| `POST` | `/api/choose-folder` | OS 폴더 선택 창 → 선택한 경로로 변경, 취소 시 `{cancelled: true}` |
| `GET` | `/api/history` | 다운로드 내역 (파일 존재 여부·크기 포함) |
| `DELETE` | `/api/history/<id>` | 기록 하나 삭제 |
| `DELETE` | `/api/history` | 기록 전체 삭제 |
| `GET` | `/api/shorts` | 현황판 목록 (+ 상태·플랫폼 정의) |
| `POST` | `/api/shorts` | 항목 생성 |
| `PUT` | `/api/shorts/<id>` | 항목 부분 수정 (보낸 필드만 덮어씀) |
| `DELETE` | `/api/shorts/<id>` | 항목 삭제 (썸네일 파일 포함) |
| `POST` | `/api/shorts/<id>/thumbnail` | 썸네일 업로드 (multipart `file`) |
| `DELETE` | `/api/shorts/<id>/thumbnail` | 썸네일 삭제 |
| `GET` | `/thumbnails/<name>` | 썸네일 이미지 |
| `POST` | `/api/shorts/lookup` | `{url}` → 제목·채널·썸네일 (자동 채우기) |
| `GET` | `/api/shorts/export` | 목록 JSON 파일 다운로드 |
| `POST` | `/api/shorts/import` | `{items, mode: "merge"\|"replace"}` → 가져오기 |

`quality` 값은 세로 해상도 숫자(`"1080"`, `"720"` …) 또는 `"audio"` 입니다.
영상은 **H.264(avc1) 코덱을 최우선**으로 골라 `bestaudio` 와 mp4로 병합하고, 오디오는 `bestaudio` 를 mp3로 변환합니다.
해당 해상도에 H.264가 없을 때만(주로 4K 이상) VP9/AV1로 넘어가며, 이 경우 화질 목록에 `⚠ VP9/AV1 (QuickTime 재생 불가)` 가 표시됩니다.

## 참고

- 유튜브 재생목록 링크를 넣으면 첫 번째 영상만 처리합니다.
- 파일명은 영상 제목 그대로 저장되며(`제목.mp4`), 같은 이름이 있으면 덮어씁니다.
- 개인 소장 목적으로만 사용하세요. 저작권이 있는 콘텐츠의 재배포는 금지됩니다.
